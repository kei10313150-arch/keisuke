# 住まいの安全チェック

写真の候補をブラウザ内のWebGPUで比較する、ビルド不要の小さなサンプルです。

## 起動

リポジトリのディレクトリで静的HTTPサーバーを起動し、表示されたlocalhostのURLをブラウザで開きます。

```sh
python3 -m http.server 8000
```

初回の解析時にはTransformers.jsとCLIPモデルの取得にインターネット接続が必要です。写真の推論処理はブラウザ内で行います。WebGPUが使えない場合は解析を停止します。

## 判定の範囲

CLIPが写真全体と四分割した各範囲について、火・煙、ガス容器、水漏れ、電気設備などの説明文との類似候補を並べます。四分割の場所は大まかな目安で、危険箇所の輪郭や正確な位置を検出する機能ではありません。画像に写らない設備内部の異常や、細かな亀裂などを見落とす可能性があります。

表示する危険度の目安は、利用者が現場で確認して選んだ兆候から決めます。AI候補の順位は確率や危険度ではなく、「兆候なし」の結果も安全を証明しません。火・煙・火花・ガス臭などがある場合は、解析結果を待たず安全な場所へ離れてください。
